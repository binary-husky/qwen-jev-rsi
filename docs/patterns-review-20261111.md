### 1

原文：语言模型可以通过长链推理处理复杂任务，但难以在亚秒级时间内响应动态环境的变化；以 JEV 为代表的 System One 决策模型可以快速响应环境变化，但由于缺乏推理能力，无法独立解决真实环境中的复杂任务。System-One RSI 为此连接两个回路：离线用推理模型监督将交互经验编码到 JEV 参数中，在线用 OODA 将快速判断转化为行动。我们探索如何让智能体从有限的真实交互中形成可复用的快速响应能力，使推理模型的知识与经验能够用于动态环境中的持续行动。

修改后：长链推理帮助语言模型处理复杂任务，却难以支持亚秒级响应。以 JEV 为代表的 System One 决策模型响应迅速，但缺乏独立处理复杂任务所需的推理能力。System-One RSI 利用推理模型指导学习，将交互经验编码到 JEV 参数中。JEV 在线输出快速判断，OODA 回路将判断转化为行动。我们希望借助有限的真实交互，让智能体逐渐形成熟练响应能力。

修改后：长链推理体现了 System 2 Thinking，帮助智能体分析复杂局面。JEV 等决策模型则体现了 System 1 Thinking，提供快速、直觉式判断。推理能力再强，也不会自动转化为熟练的行动能力。决策即使正确，返回过晚仍可能导致失败。快速输出同样不等于掌握任务。System-One RSI 将推理经验用于训练，让快速判断能力随交互不断改进。
