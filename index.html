System-One RSI：面向语言模型智能体的外置肌肉记忆

系统一递归自我改进（System-One Recursive Self-Improvement, System-One RSI）

长链推理帮助语言模型处理复杂任务，却难以支持亚秒级响应。以 JEV 为代表的 System One 决策模型响应迅速，但缺乏独立处理复杂任务所需的推理能力。System-One RSI 利用推理模型指导学习，将交互经验编码到 JEV 参数中。JEV 在线输出快速判断，决策回路将判断转化为行动。我们希望借助有限的真实交互，让智能体逐渐形成熟练响应能力。

OODA 指观察、研判、决策与行动循环（Observe, Orient, Decide, Act）。

1研究问题

长链推理体现了 System 2 Thinking，帮助智能体分析复杂局面。JEV 等决策模型则体现了 System 1 Thinking，提供快速、直觉式判断。推理能力再强，也不会自动转化为熟练的行动能力。决策即使正确，返回过晚仍可能导致失败。快速输出同样不等于掌握任务。System-One RSI 将推理经验用于训练，让快速判断能力随交互不断改进。

理解游泳原理不等于已经会游泳。练习者仍需学习如何协调呼吸与划水，并调整打腿节奏和身体姿态。人学习游泳时，似乎不必像传统强化学习算法那样经历数千次试错。这一观察启发了本文的设想。教师用语言提示动作要领，练习者借助反馈调整动作，逐渐形成肌肉记忆。

我们用这一类比理解 JEV 与推理模型的关系。面对难以沙盒化且要求实时响应的环境，推理模型指导 JEV 学习任务知识。交互经验经训练进入模型参数，成为可快速调用的能力。JEV 由此承担推理模型的外置肌肉记忆。

推理为练习指明方向，熟练响应则需要在实际交互中形成。现有方案对交互条件各有要求，环境能否复制、示范是否易于采集，都会影响学习过程。

方案优点缺点
在线强化学习（Online Reinforcement Learning, RL）通过奖励反馈学习策略，适用于多种任务，便于大规模扩展。一些复杂环境极难沙盒化。例如，在线账号验证会妨碍环境复制、重置与大规模并行训练，阻断传统在线强化学习的应用。
离线强化学习（Offline RL）通过奖励反馈学习策略，适用于多种任务，便于大规模扩展。非标准化环境往往难以采集示范。采集成本过高时，传统离线强化学习也难以应用。
单独的 System One 决策模型提示词调优快速决策，具备一定的直觉式响应能力。简短提示词或少量图像输入容易在具体问题下丧失精度；较长提示词或多幅图像输入容易推理耗时增加至原来的两倍，无法满足实时决策要求；部分多模态任务难以通过自然语言充分描述（接近零的精度，必须微调模型）。
推理模型编写视觉决策器利用推理模型编写视觉检测与控制代码，便于处理简单的交互任务。计算机视觉（Computer Vision, CV） 需要大量测试，面临几乎无穷的边界情况，而且容易被利用或绕过。
单独的推理模型采用典型的 Computer Use 决策流程。不考虑实时性时，拥有完美的决策能力。每次决策都需要数秒，无法参与高频实时决策。

这些方案分别受到环境难以复制、示范数据难以采集、决策耗时较长或任务难以描述等因素的限制。对于提示词调优，输入长度需要控制，影响决策的视觉差异也必须表达准确。

自然语言描述多模态任务的局限

动作时机判断依赖细微的视觉差异。同一句自然语言描述可能覆盖多个视觉状态，而这些状态要求不同的响应。

在 Black Myth: Wukong 中，智能体需要根据攻击准备动作判断闪避时机。对手先蓄力，随后改变武器角度（第 2 帧）。短暂停顿后（第 3 帧），对手发起攻击（第 4 帧）。第 2、3 帧都能被描述为“举着武器蓄力”，但留给智能体的反应时间不同。仅识别“正在蓄力”还不够，模型需要结合近期画面判断动作阶段。

仅靠提示词调优，模型很难区分第 2、3 帧。提示词需要描述人物姿态与武器角度，还要说明这些特征如何变化。参考图像补充文字信息，却不能消除时序判断的困难。描述过于简略，模型容易混淆阶段；增加细节，也未必能准确传达决定行动时机的特征。

这种方法将改进判断准确率的压力集中在每次调用的输入上。加长提示词、增加参考图像或引入更多历史帧，都可能增加处理开销，延长响应时间。即使判断正确，结果返回时若已错过闪避窗口，决策仍然无效。这类任务既要求判断准确，也要求及时响应，仅靠提示词调优很难同时满足这两个要求。

因此，System-One RSI 将部分优化过程转移到离线学习阶段。系统利用交互序列和受击时刻构建训练样本，通过 LoRA 微调，使 JEV 学会辨别动作的不同阶段。在线运行时，JEV 根据简洁的输入预测受击前的剩余时间，行为树据此选择并执行动作。关键的视觉差异由模型通过训练掌握，无需在每次调用时反复描述。提示词仍用于定义问题和调整输出，细粒度的时序判断则由适配后的模型完成。

2方法：连接离线学习与在线决策

System-One RSI 用交互记录训练 JEV，将任务判断能力保存在模型参数中。在线运行遵循 OODA 回路。JEV 从环境观测中输出结构化判断，控制规则据此选择动作。执行接口将动作作用于环境，新记录再用于训练和更新。整个决策过程无需逐步生成推理文本。

JEV 将环境观测转化为任务相关的结构化判断，控制器据此选择并执行动作。交互记录返回离线学习回路，用于更新判断模型、修订控制规则，或同时改进两者。

要持续运行上述双回路，还需要把探索、标注、训练和部署组织成协作流程。图 3 展示各智能体如何围绕同一个任务分工，并根据交互结果选择下一步优化方向。

当瓶颈来自行动规则时，系统调整提示词与行为树。任务判断不足时，则利用交互样本训练 JEV。

方案的优点

  1. 少量真实交互即可学习。面向无法沙盒化、无法并行运行的非仿真环境，通过少量实际交互形成任务能力。
  2. 保持低延迟的决策回路。推理与学习的成果进入 System One 模型，在线调用即可快速获得判断。OODA 回路据此持续执行动作。
  3. 利用先验知识构建初始策略。网页搜索和人类描述提供任务知识。少量探索性交互补充环境反馈，用于修订初始策略。
  4. 支持多种优化模式。推理模型帮助定位性能瓶颈。系统可固定 JEV 参数，集中修改行为树；也可固定行为树，训练 JEV。
  5. OODA 策略便于修改和迁移。行为树明确记录判断与动作之间的关系。角色切换等任务变化通常只需调整部分规则，不必重新训练模型。
  6. JEV 可配合不同任务调整判断内容。推理模型增删提示词，修改需要判断的状态。结合行为树调整，适配后的 JEV 可用于更复杂的策略。
  7. 无需专家操作示范。训练样本来自环境交互，不采集人类操作数据。公开文本与图像仍用于提供任务知识。

6讨论与局限

  • 跨场景迁移仍需适配。本文实验用少量交互样本解决特定任务，不采集专家操作示范。完成 2–3 次迭代所需的数据，可在约 1–10 小时内采集。形成的策略仍依赖当前环境。迁移时可能需要修改提示词与行为树，并采集新数据。
  • 初始策略依赖先验知识。不采集专家操作示范，并不意味着不需要人类知识。公开材料与人类描述提供任务背景，如能量机制和角色技能。这些知识帮助确定观测目标与可选动作。先验缺失或不准确时，策略构建会更困难。
  • 低延迟运行需要相应硬件。当前部署使用至少两块 GPU，分别承担环境渲染与 JEV 推理，减少资源竞争。这增加了硬件成本，也限制了单 GPU 设备上的直接部署。
