System-One RSI：面向语言模型智能体的外置肌肉记忆

System-One Recursive Self-Improvement · 从推理模型监督到快速任务判断

语言模型可以通过长链推理处理复杂任务，但无法完成亚秒级的动态环境响应；以 JEV 为代表的 System One 决策模型可以快速响应环境变化，但受限于推理缺失，无法独立解决真实环境中的复杂任务。System-One RSI 为此连接两个回路：离线用推理模型监督将交互经验编码到 JEV 参数中，在线用 OODA 将快速判断转化为行动。我们探索如何让智能体从有限的真实交互中形成可复用的快速响应能力，使推理模型的知识与经验能够用于动态环境中的持续行动。

1研究问题

从 System 1 与 System 2 Thinking 的视角看，长链推理体现了 System 2 式的深思熟虑，让智能体能够分析复杂局面；以 JEV 为代表的决策模型则提供了 System 1 式的快速、直觉性判断。然而，强大的 System 2 推理并不会自动形成 System 1 的熟练响应能力。逐步推理可以给出正确决策，但正确而迟到的决策仍然可能失败；快速输出也不意味着已经掌握任务。关键问题是：如何将 System 2 的知识与推理经验，转化为 System 1 可快速调用、并能从交互中持续改进的能力？

以游泳为例，一方面，即使理解了游泳的全部原理，也不等于已经会游泳：呼吸节奏、划水、打腿与身体姿态的协调，仍然需要通过实际练习形成熟练的控制能力。另一方面，人似乎也不需要像传统强化学习算法那样，经历数千次试错才能学会游泳。我们认为，关键在于人能够通过有思考、有目的的练习，有针对性地形成“肌肉记忆”。

用这一视角理解 System One LLM（JEV 模型）与 System Two LLM（推理模型）的关系，我们探索一种基于现有模型架构的 RSI 范式：面向难以沙盒化、对实时性要求高的环境，由 System Two LLM 运用推理能力指导 System One 模型的学习与优化，将任务知识和交互经验沉淀为可快速调用的能力，使 System One 模型成为推理模型的外置“肌肉记忆”。

现有方案的优点与缺点

方案优点缺点
在线强化学习（Online RL）在任意目标环境中学习任意策略的终极通用方案。简洁、高效、易于大规模扩展。一些复杂环境极难沙盒化，使其难以被复制、重置并用于大规模并行训练（例如要求在线账号验证等），这阻断了传统在线强化学习的应用。
离线强化学习（Offline RL）在任意目标环境中学习任意策略的终极通用方案。简洁、高效、易于大规模扩展。非标准化的环境中，通常示范数据采集也面临较高的实施成本，这阻断了传统离线强化学习的应用。
单独的 System One 决策模型提示词调优快速决策，具备一定的直觉式响应能力。简短提示词或少量图像输入容易在具体问题下丧失精度；较长提示词或多幅图像输入容易推理耗时增加至原来的两倍，无法满足实时决策要求；部分多模态任务难以通过自然语言充分描述（接近零的精度，必须微调模型）。
单独的推理模型：生成 CV/OODA 决策器利用推理模型编写视觉检测与控制代码，便于处理简单的交互任务。CV 需要大量测试，面临几乎无穷的边界情况，而且容易被利用或绕过。
单独的推理模型采用典型的 Computer Use 决策流程，在不考虑实时性的情况下，拥有完美的决策能力每次决策都需要数秒，无法参与高频实时决策。

为什么有些多模态任务难以用自然语言描述？

下面以动作时机判断为例，具体说明“单独的 System One 决策模型提示词调优”的局限：同一句自然语言描述可能对应不同的视觉状态，而这些细微差异恰好决定了正确的行动时机。

在《黑神话·悟空》中，Agent 需要根据对手的攻击准备动作精准判断闪避时机。上面四帧展示了这一难点：对手先缓慢蓄力，期间轻微转动武器角度（第 2 帧），到第 3 帧之后再短暂停顿，随后发起攻击（第 4 帧）。第 2、3 帧都可被粗略描述为“对手举着武器蓄力”，但对应的剩余反应时间不同。仅识别出“正在蓄力”并不足以决定何时闪避；模型还需要结合近期变化判断动作进行到了哪个阶段。

对于单独依赖提示词调优的 System One 决策模型，要区分第 2、3 帧，就需要用语言描述姿态、手部动作、武器角度及其随时间的变化，或补充参考图像。困难在于，这些视觉差异并不容易转化为明确、稳定、可复用的自然语言规则。文字简略时会混淆不同阶段；增加细节也不等于已经准确表达了决定行动时机的特征。

这使性能改进更加依赖每次在线调用的输入设计。长提示词、多张参考图和历史帧处理不当，会增加图像编码、上下文处理及推理开销，使端到端延迟显著上升。即使最终判断正确，如果结果返回时已经错过闪避窗口，仍然无法形成有效的实时决策。对于这类任务，正确率与响应时限必须同时满足；只优化提示词并不能保证二者兼得。

System-One RSI 因而将部分优化过程转移至离线学习阶段：利用交互序列与受击时序构建监督，通过 LoRA 微调让 JEV 学会任务相关的阶段差异，在线再以紧凑输入输出受击前剩余 tick 数等结构化判断，由行为树选择并执行动作。这种做法将对重复细节描述的依赖转化为参数化的任务能力。提示词仍可用于定义问题和调整输出，但不再单独承担全部细粒度时序辨别任务。

当前工作已经使用推理模型标签和控制代码，并进行了真实环境部署；少样本优势及不同知识来源的独立贡献仍需验证。

2方法：连接离线学习与在线决策

System-One RSI 将学习和执行组织为两个相互连接的回路。离线回路利用交互日志和推理模型监督进行任务适配，将特定任务的感知与判断能力保存在模型参数中，形成可在线调用的外置“肌肉记忆”。在线回路遵循 Observe–Orient–Decide–Act（OODA）：获取环境观测，调用 JEV 直接输出结构化判断，通过控制规则选择动作，再通过执行接口作用于环境，从而支持无需逐步生成推理文本的快速决策。交互产生的新记录再进入离线回路，用于后续学习与更新。

JEV 将环境观测转化为任务相关的结构化判断，控制器据此选择并执行动作。交互记录返回离线学习回路，用于更新判断模型、修订控制规则，或同时改进两者。

Multi-Agent System One RSI Engineering

方案的优点

  1. 少量真实交互即可学习。面向无法沙盒化、无法并行运行的非仿真环境，通过少量实际交互形成任务能力。
  2. 保持低延迟的决策回路。将推理与学习的成果沉淀到 System One 模型中，结合OODA循环，以低延迟完成在线判断，支持高频实时行动。
  3. 高效利用先验知识构建初始策略。将网页搜索、人类提供的非形式化描述中的已有知识，与少量探索性交互（monkey testing）获得的环境反馈结合，高效转化为初期学习与优化的依据。
  4. 支持多种优化模式的灵活切换。借助推理模型，可准确定位当前 OODA 策略的性能瓶颈，有针对性地选择（1）冻结JEV模型参数以优化行为树，或（2）冻结行为树以优化JEV参数。
  5. OODA决策循环的良好可迁移性。OODA决策循环有良好的可读性和可维护性，例如实验证明，在游戏场景中，当从一个角色迁移到新角色时，大多数情况下只需要推理模型对行为树做出少量修改即可完成策略迁移，并不需要重新训练。
  6. JEV模型的良好可迁移性。大多数JEV模型本身有良好的可迁移性，微调后并不会明显削弱其他问题上的决策能力，无论是微调前后，都可以配合推理模型增删提示词或者修改决策维度。配合OODA中行为树的修改，可短时间内稳健实现更为复杂的策略。
  7. RSI 学习回路具有直观的解释性。本文方法可以用人和动物的学习行为进行直观类比，容易理解和拓展。
  8. 无需人类专家示范样本。在某些场景下，即使人类也需要经过大量练习才能够提供有价值的训练样本。在本方案中，我们不使用也不采集任何人类操作数据（网络上以文本、图像为主的公开材料除外）。

从模型适配到控制策略迭代

RSI 也可以作用于模型之外：利用外部知识改进感知提问与行动规则，再在真实环境中检验。以下是一组独立的跨对手控制器实验，比较 zzz-rsi-v2 与 zzz-rsi-v3 控制器；不与上方模型训练实验合并。

  • 跨对手应用：在有限对手上开发策略后，用冻结版本评测另外 9 个对手；其中 6 个至少完成过一局，完成局均为 S。该结果展示多对手应用的可行性，不代表所有尝试均成功。
  • 模型之外的 RSI：本轮报告未进行权重训练，实际更新包括感知提问、状态字段和行为树。两组均调用同一服务端点，但缺少服务端权重指纹，尚不能独立确认两组权重完全相同。
  • 借助外部知识：实验方报告使用技能机制知识指导规则修改。代码差异包含连续动作链和招架后 0.9 秒切回主角色等变化；外部检索过程尚未独立审计，各规则的贡献也未单独消融。

5黑神话·悟空：受击预测与闪避

在《黑神话·悟空》中，系统使用 JEV-27B-VL 与 LoRA 预测受击前剩余的离散时间步（tick）数量，再由控制规则触发闪避。输入由四帧历史图像与当前帧组成（640×450）；模型读取七个候选 token 的 logits 给出判断，不逐步生成推理文本。项目记录的单次前向约为 200 ms，完整控制周期还包含观察与动作执行开销。

6讨论与局限

本文提出的 System-One RSI 展现了在少量真实交互中形成实时决策能力的潜力，但其适用范围、知识依赖与部署条件仍存在以下局限。

  1. 策略的跨场景泛化仍然有限。本研究侧重在不使用人类专家操作数据的条件下，以极少量样本解决特定场景中的 OODA 决策问题。在本文探索的场景中，完成 2–3 次 RSI 迭代所需的数据可在约 1–10 小时内采集，但由此形成的策略仍高度依赖当前任务与环境，难以直接泛化到其他场景。迁移到新场景时，仍可能需要调整提示词与行为树，并重新采集交互数据进行适配。
  2. 初始决策树依赖外部先验知识。无需专家操作示范，并不意味着无需人类知识。初始决策树的构建仍依赖网络公开材料与人类提供的任务先验，例如游戏中的能量机制、技能用途和角色专长。这些知识帮助系统确定需要感知的状态与可采用的动作；当先验缺失或不准确时，初始策略的构建与后续优化会更加困难。
  3. 低延迟部署具有硬件要求。为降低 JEV 模型的推理延迟，当前方案需要至少两块 GPU 协同工作，分别承担游戏渲染与 JEV 推理，以减少资源竞争。这一部署要求增加了硬件成本，也限制了方案在单 GPU 或资源受限设备上的直接应用。
